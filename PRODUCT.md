# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

ohCRUD PHP microframework, SQLite 3, Semantic HTML5, Vanilla CSS3, modern Vanilla ES6+, Google Material Symbols

## Users

Self-hosters, privacy-conscious individuals, and personal cloud operators managing their personal file libraries, documents, photos, media collections, and archives.

## Product Purpose

Altus is a fast, lightweight, single-user personal cloud storage system modeled after core file-management features of Google Drive and Nextcloud, providing frictionless disk-to-database synchronization, direct physical filesystem parity, instant search, responsive folder browsing, media streaming, and inline file previews without framework bloat.

## Positioning

Direct Physical Filesystem Storage with sub-second disk-to-DB reconciliation ("Quick Sync"). Files and directories in storage directly mirror their actual names and hierarchy on host disk without obfuscated hashes or synthetic folder UUIDs, coupled with zero-framework Vanilla frontend craft.

## Mode

Operate

## Confirmed Conventions & Constraints

- Zero third-party UI frameworks (pure Semantic HTML5, Vanilla CSS3, modern Vanilla ES6+; no React, Vue, Tailwind, or Bootstrap).
- Exclusively Google Material Symbols / Material Icons for iconography.
- Persistent desktop sidebar with storage quota and navigation, collapsing to mobile off-canvas drawer on viewports < 1024px.
- High-contrast, scan-friendly data tables and grid cards adhering to Impeccable Operate guidelines.
